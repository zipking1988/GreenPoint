# GreenPoint landing research brief

Date: 2026-10-31, Japan time. Audience: hackathon judges and Japanese agricultural operators. Scope: immediate landing-page clarity, evidence, interaction and trust. This is a prelaunch concept; no GreenPoint customer or complaint evidence is available.

## Executive read

The strongest story is the change from repeated camera observations to one reviewable plant inventory. The prior page had attractive agricultural imagery but placed its first product action below the hero. The selected dark visual direction makes computer vision more apparent, while the complete field map makes the intended output understandable. A finite, manually controllable identity explanation is a more useful signature interaction than a generic image carousel. Public policy and model documentation can support context and proposed architecture, but cannot establish GreenPoint accuracy or pesticide savings. The landing must make its presentation prototype available now while keeping model validation and field trials visibly separate.

## Ranked opportunities

1. **Product comprehension, high severity / high confidence:** observed in the prior source, the hero lacked an English product explanation and CTA. Add phone-video-to-plant-map copy and a first-viewport walkthrough action. Frequency is unknown; this is an interface finding, not user-research prevalence.
2. **Technical credibility, high severity / high confidence:** prior interaction swapped unrelated stills. Explain the same plant across repeated views, with manual scrubbing and a finite replay. The prediction that this helps judges understand the custom tracker is an inference.
3. **Trust and evidence, high severity / high confidence:** documentation lists future targets, not measured results. Label public policy context, simulated visuals, proposed architecture and planned evaluation. Avoid invented customers, confidence scores and achievements.
4. **Map usefulness, medium severity / high confidence:** previous CSS cropped the complete plot. Preserve natural image ratio, add sample inspection, keyboard/touch controls and a clearly labeled sample CSV.
